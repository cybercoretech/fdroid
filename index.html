    03 / Trust model

    Two signatures,
    both checked.

    F-Droid verifies the repository index signature on every refresh, and Android verifies every APK update against the developer key it was first installed with. Neither key is stored on GitHub.

    RELEASE

    Each app is built and signed with its own developer key on the maintainer's machine, then published on GitHub with its SHA-256.

    VERIFY

    Before listing, every APK's checksum and signing certificate are re-checked against the pin in apps.tsv.

    INDEX

    fdroidserver builds the index and signs it with the repo key DE37…F3C3.

    UPDATE

    Your phone checks the index signature, then Android checks the new APK is signed like the installed one.

    GOOD TO KNOW
    • Same APKs as GitHub: installing from here, Obtainium or the GitHub release is interchangeable; updates work across all three.
    • Self-hosted apps: Holodrive Photos and Nightwatch talk to servers you run (flagged SELF-HOSTED).
    • Not the main F-Droid catalog: F-Droid doesn't build these APKs; Cybercore signs them. Main-catalog listings may follow once builds are reproducible.
    • Prefer a computer? Each app's README has a verifying curl … | sh installer for adb.
